# Interview Notes

This project was built to demonstrate a ground control system-style architecture.

Key points to explain in an interview:

1. Why binary telemetry was used
2. How UDP packet flow is handled
3. Why CRC validation matters
4. How gateway, server, and dashboard are separated
5. What parts would need improvement for real mission use

This is not certified flight or mission software.
It is a portfolio project focused on architecture, communication, and verification flow.
